# gavinyue.com

Personal tech blog built with Hugo and the Blowfish theme.

## Local

```
hugo server
```

## New post

```
hugo new content posts/my-post.md
```

## Deploy — GitHub Pages

Push to `main`. The GitHub Actions workflow builds the Hugo site and deploys it
to GitHub Pages automatically.

In the repository settings, set **Pages → Build and deployment → Source** to
**GitHub Actions**.
